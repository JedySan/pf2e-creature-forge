# Кузня существ

Конструктор монстров и NPC для **Pathfinder 2e (Remaster)** в Foundry VTT. Все числа берутся из
таблиц GM Core «Building Creatures» для уровня существа — остаётся придумать концепцию и способности.

## Установка

**Setup → Add-on Modules → Install Module → Manifest URL:**

```
https://github.com/JedySan/pf2e-creature-forge/releases/latest/download/module.json
```

Требуется система **pf2e**, Foundry v13–v14.

> ID модуля — `jedysan-kuznya`. До версии 0.2.0 он был `pf2e-creature-forge` и совпадал с чужим модулем
> «PF2E Creature Forge» из каталога Foundry — при обновлении Foundry мог подменить им Кузню.
> Если у вас стоит «PF2E Creature Forge» 1.1.x вместо Кузни — удалите его и установите Кузню заново по ссылке выше.

## Мастер

Вкладка **Актёры → кнопка «⚒ Кузня существ»** (видна ГМу).

1. Название, уровень (−1…24), размер, редкость.
2. **Роль** по «дорожным картам» GM Core — расставит ступени всех характеристик:

   | Роль | Суть |
   |---|---|
   | Сбалансированный | всё средне |
   | Громила | экстр. Сила, высокие HP и Стойкость, низкий КБ, экстр. урон |
   | Солдат | высокий КБ и Стойкость, высокие удары, Реактивный удар |
   | Застрельщик | высокая Ловкость и Рефлекс, +10 фт скорости |
   | Снайпер | сильный дальний удар, высокое Восприятие, мало HP |
   | Магический боец | высокие удары + врождённые заклинания |
   | Заклинатель | высокий КС заклинаний, мало HP, слабые удары |
   | Мастер навыков | много высоких навыков |

3. У каждой характеристики — **ступень** (экстремальная / высокая / средняя / низкая / ужасная)
   или «Своё» число. Значение пересчитывается сразу.
4. **Удары** — атака и урон по таблице, тип урона, трейты, дальность, доп. урон (`1d6 fire`).
5. **Заклинатель** — традиция, тип (врождённые / подготовленные / спонтанные), КС и атака по таблице,
   поиск заклинаний в компендиуме с ограничением ранга по GM Core.
6. **Сопротивления, слабости, иммунитеты** — значения по таблице (макс. — для узких, мин. — для широких).
7. **Способности** из компендиумов pf2e: Захват, Реактивный удар, Сбить с ног, Регенерация…
8. Внизу — **проверка баланса** (перекос экстремальных и низких значений).

Существо создаётся в папке актёров «Созданные враги» (имя — в настройках модуля). Туда же PF2e Claude Bridge кладёт импортированных монстров; старые папки «Кузня существ» и «Claude — энкаунтеры» при запуске сливаются в неё.

## Свои способности

В разделе «Способности» мастера — кнопка **«＋ Своя способность»**: название, тип действия
(пассивная, реакция, 1–3 действия), описание и **теги** (трейты pf2e: аура, эмоция, страх, вода…).
Теги можно вводить по-русски или ключами; Кузня сама подсказывает подходящие по названию и описанию —
клик по подсказке добавляет тег. Если теги не заданы, при создании подставляются подсказанные.

## Подсказки в листе NPC

Рядом с КБ, HP, спасбросками, Восприятием и характеристиками в листе любого NPC — метка ступени
для его уровня (наведите — вся шкала). По умолчанию выключено — включается в настройках модуля
(«Подсказки тиров в листе NPC»).

## Смена уровня готового NPC

У любого NPC (не только из Кузни) — кнопка **«Сменить уровень»** в шапке листа
или **правый клик по актёру → «Сменить уровень (Кузня)»**. Укажите новый уровень — все числа
пересчитаются по таблицам GM Core: каждая характеристика сохраняет свою ступень и ручные поправки
(«высокий КБ +1» останется «высокий +1»). Атаки, урон, КС заклинаний, сопротивления — тоже.
Можно создать копию, не трогая оригинал.

## API (для Claude и макросов)

```js
const forge = game.modules.get("jedysan-kuznya").api;
forge.open(spec);            // открыть мастер с заготовкой
await forge.create(spec);    // создать сразу → { actor, stats, warnings, missing }
forge.preview(spec);         // посчитать числа без создания
forge.applyRole(spec, "brute");
await forge.rescale(actor, 17, { copy: true }); // сменить уровень NPC
```

Спецификация описана в `scripts/builder.js`. Пример:

```js
{
  name: "Болотная ведьма", level: 8, size: "med", traits: ["humanoid", "human"],
  role: "spellcaster",
  attributes: { int: "extreme", con: "low" }, ac: "low", hp: "low",
  saves: { fortitude: "low", reflex: "moderate", will: "high" },
  strikes: [{ name: "Посох", damageType: "bludgeoning", attack: "low", damage: "low" }],
  spellcasting: { tradition: "occult", type: "prepared", tier: "high", attribute: "int",
                  spells: [{ name: "Fear", rank: 3 }, { name: "Slow", rank: 3 }] },
  iwr: [{ kind: "weakness", type: "fire", value: "min" }],
  abilities: [{ name: "Grab" }]
}
```

С **PF2e Claude Bridge** Claude собирает существо по описанию («@Гриша сделай болотную ведьму 8 уровня»)
и открывает мастер с готовой заготовкой — вы проверяете и жмёте «Создать».
